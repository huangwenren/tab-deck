Tab Deck Privacy Policy

Your tabs and Library data stay on your device.

Tab Deck processes the titles and URLs of currently open tabs to organize them. It does not read or store your Chrome browsing history, and it never sells personal data.

Data stored locally

Saved for later items, Archive entries, notes, tags, Workspaces, preferences, recovery points, and an anonymous analytics identifier (only if analytics is enabled) are stored in chrome.storage.local. Tab Deck also processes currently open tab titles and URLs in memory. This data is used only to provide the features you request.

Removing the extension can remove its local data. Export a backup from Data & Recovery if you want to keep it.

Optional anonymous analytics

Analytics is off until you explicitly allow it. When enabled, Tab Deck sends allowlisted feature-event names, the extension version, the interface surface, an anonymous identifier, and numeric counts through the Tab Deck Cloudflare Worker to Google Analytics. It never sends tab URLs, page titles, domains, page content, notes, tags, bookmarks, or browsing history.

Permissions

Tab Deck uses required Chrome permissions to manage open tabs, save local data, schedule snoozed items, preserve tab groups, and load favicons locally. Bookmark access is requested only when you choose to import Chrome bookmarks. Notification access is requested only when you create a Snooze reminder.

Your choices

Choosing “Continue without analytics” keeps analytics off and leaves every product feature available. You can change the analytics preference at any time in the popup. Disabling it stops future events and removes the local anonymous identifier.

Chrome Web Store data use

Tab Deck's use of information received from Chrome APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Contact

For privacy questions, open an issue at github.com/huangwenren/tab-deck/issues.
